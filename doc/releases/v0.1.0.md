# Amadeus v0.1.0 — Windows 体验版

## 安装与使用

下载 Release 中的 **Amadeus-Windows-Setup-0.1.0.exe**，安装后打开 **设置 → 常规 → 在这台电脑上运行 → 一键安装并启动**。

首次安装环境需要联网，后续可一键启动；不需要 Linux、WSL 或手动安装 Python/Node.js。也支持提前只安装环境、打开应用时自动启动、停止服务及查看日志。

## 本次内容

- 正式项目整合实时语音服务商适配与配置、ASR 和任务大脑入口。
- Windows 本机后端生命周期与独立 Python 环境管理。
- ASR 权重智能下载：6 类引擎、10 个版本；大陆优先国内仓库或镜像，其他地区优先官方 HF/GitHub，支持手动换源、暂停续传、完整校验和自动保存。
- 本地 GLB 导入、主窗口与无边框透明桌宠共享模型、实际音频驱动口型。
- 补充 `.gitignore`，排除密钥、依赖、模型权重、角色模型、研究输出和构建产物。

## 角色资源

**公开源码和安装包不包含第三方角色 GLB、贴图包或 Blender 工程。** 在 **设置 → 本地 3D 模型** 导入自行准备且有权使用的 GLB，模型只保存在本机。普通静态模型可显示；口型和动作需要相应形态键及骨骼。没有角色模型也可以使用语音和 ASR。

## 验证与已知边界

- 已在实际 Windows 打包应用中验证原生文件选择导入、主窗口/桌宠渲染以及 PCM 口型。
- 已验证 Windows 独立环境安装、修复、启停和自动启动。
- Whisper tiny 已完整通过权重下载、暂停续传、校验、CPU 加载和中文识别；其他模型尚未逐个完成大权重/GPU 推理验收。
- SenseVoice/FireRed 等引擎可能还需配套官方源码；GPU 驱动和 FFmpeg 不包含在基础安装中。界面区分权重与运行组件状态。
- 镜像服务可发生上游重定向，网络可用性取决于当前网络。实时 API 需要使用者自己的账号、密钥和额度。
- 此体验版未做 Windows 代码签名，安装时可能显示未知发布者。可使用随附 SHA256SUMS.txt 校验文件。
