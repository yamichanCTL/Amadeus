# 模型智能下载

打开 **模型管理 → ASR 模型设置 → 下载本地模型**。

1. 选择模型，界面显示预计权重大小与自动保存位置。
2. 选择 **中国大陆** 或 **其他地区**。初始建议只依据系统时区，可手动修改，不进行 IP 定位。
3. 保留 **智能选择** 并点击 **智能下载**，或手动指定该模型支持的来源。
4. 等待下载和校验完成。下载期间可查看速度、文件和进度，也可暂停再继续。
5. 点击 **设为识别模型**，再按模型要求安装运行组件、选择 CPU/GPU 并加载。

大陆优先已核实的国内 ModelScope 或 HF-Mirror；其他地区优先官方 Hugging Face / GitHub。并不是每个模型在每个平台都有兼容的权重，因此下拉菜单只列本次核实过的来源。HF-Mirror 明确标注为第三方镜像，使用由官方仓库核验过的固定版本清单检查内容。

镜像的部分文件可能重定向至 Hugging Face，不能保证所有地区都能直连；智能选择会在来源失败后换源。内置清单避免了查询 Hugging Face API 的依赖，实际下载仍取决于当前网络。

下载放在当前**后端所在电脑**，按对应引擎配置的模型路径保存。如果连接的是远程后端，文件不会下载到前端所在电脑。大文件先写入临时目录，完整性校验完成后才进入正式模型目录。替换已有目录时保留备份；模型正在加载使用时，需要先卸载。

## 权重和运行组件

两种状态分别显示。下载权重不会自动安装 GPU 驱动，也不会把下载的代码直接执行。

通过 Windows 一键环境运行的本机服务可点击 **安装 Python 运行组件**。该操作会停止并重新启动本机后端，已有的运行组件选择会在后续环境修复时保留。开始前应暂停下载并结束语音会话。远程后端需在对应电脑准备运行环境。

SenseVoice、FireRedASR2 当前适配器还需要配套的官方推理源码；界面会显示这一条件，不能把“权重已下载”当作“可立即推理”。X-ASR 可先使用 CPU；CUDA 模式还取决于 sherpa-onnx 构建及驱动。

模型清单、格式与官方来源核验见 [来源记录](../model-download-sources.md)。

## Blender / 3D 数字人资源

公开版本不附带第三方角色 GLB 或 `.blend`，使用者通过 **设置 → 本地 3D 模型** 导入自己有权使用的资源。模型仅复制到本机应用数据目录，不上传。后续合法可分发资源的托管地址尚未确定，因此没有上线远程数字人下载。

取得相应分发许可的资源，可把**运行用 GLB**与**可编辑 `.blend` 工程**分别发布。用户运行桌面数字人通常只需要 GLB；`.blend` 可以保留为可选的编辑资源。可以为同一版本提供一个海外 HTTPS 下载地址和一个大陆 HTTPS 地址，两端使用完全相同的文件。

已提供本地清单生成器，记录版本、文件名、大小、SHA-256 和两地地址：

```powershell
python scripts/digital_human/create_distribution_manifest.py frontend/desktop/public/pet/aemeath-digital-human.glb --version v03 --output .runtime/aemeath-resource.json
```

提供托管地址后，增加 `--global-url` 和 `--mainland-url` 即可生成可核验清单，再接入运行端资源切换。脚本只写本地清单，不上传资产。发布渠道可以是 GitHub Releases 或对象存储；模型许可说明应随对应版本一起提供。
