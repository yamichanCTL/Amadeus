# Windows 一键安装与启动

## 给使用者

1. 运行 `Amadeus-Windows-Setup-0.1.12.exe`，按向导选择安装位置。
2. 打开 Amadeus，在 **首页** 准备本机环境；如果已有后端，也在首页连接。
3. 点 **一键安装并启动**。程序会联网下载 Python 与锁定版本的基础依赖，安装进自己的目录；进度与失败原因会显示在界面。
4. 出现 **运行中 / 当前已连接** 后，进入首页的 **实时对话** 等任务卡片，选择所需模型。已有 API 连接可复用。
5. 如需 3D 数字人，在 **设置 → 角色与桌宠 → 本地 3D 模型** 导入自己有权使用的 GLB。公开版不附带角色模型；没有模型也可使用语音功能。导入有口型形态键的模型后，可用 **试听口型** 本地检查，不需要 API Key。

无需 Linux、WSL、Docker、管理员权限，也不用自己安装 Python、Node.js 或输入终端命令。前端已经包含在安装包内。

也可以提前点 **只安装环境**，使用时再点 **启动本机服务**。开启 **打开 Amadeus 时自动启动** 后，下次打开应用会自动启动已安装的服务；这个选项不会偷偷下载尚未安装的环境。

首次安装需要网络。下载时间取决于网速；失败后可以查看日志并重试。后续启动已安装环境不需要重新下载依赖。云端模型对话仍需联网，并遵循模型提供方的额度与收费规则。

## 环境与数据在哪里

首页的 **数据存储位置** 显示当前实际目录，可在安装前选择其他磁盘。新安装默认使用程序目录旁的 `AmadeusData`，例如程序在 `D:\Apps\Amadeus`，大体积数据在 `D:\Apps\AmadeusData`。默认位置不可写时会要求选择位置，不会悄悄退回 C 盘。

| 子目录 | 内容 |
| --- | --- |
| `runtime` | 后端代码、Python 虚拟环境、安装日志；本机服务密钥位于 `runtime/app/backend/.env` |
| `python` | 程序专用 Python |
| `models` | 模型权重，具体路径同时显示在模型下载页 |
| `cache` | uv、pip、Hugging Face、ModelScope、Torch 等缓存 |
| `tmp` | 受管安装器、后端和桌面抽音的临时文件 |
| `backend-data` | 数据库、音频、转写、TTS 与 Agent 运行数据 |
| `avatars`、`archive` | 导入角色副本、默认录音与导出归档 |

AppData 中仍有少量界面配置、浏览器缓存和目录指针；系统驱动、外部 CLI 和用户另选的归档或共享模型目录不受此位置管理。

**旧版升级不会自动搬迁大文件。** 检测到旧 `local-runtime` 时继续沿用；选择新位置会创建新环境，需要重新安装并下载模型。旧文件会列在“保留的旧位置”，不会自动删除。由于 Python 虚拟环境含绝对路径，不能直接剪切后声称可用。切换时仅清除指向旧受管目录的模型/归档路径配置，外部自定义路径保留。

不再需要的数据可展开 **查看目录明细与清理选项**，停止本机服务后清理。程序只清理具有本应用有效所有权标记的目录，并要求再次确认；共享缓存、链接指向的位置及无法识别的旧目录不会自动删除。删除中途失败会提示可能已部分删除，需修复环境。普通交互式卸载也提供受管数据清理选择；升级与静默卸载默认保留数据。

## 下载过程会显示什么

Python 与依赖安装展示当前阶段、组件名称/版本、已知文件大小、已就绪项目数、耗时、最近事件以及缓存磁盘占用。缓存复用不会算作新下载。uv 的管道日志不提供持续字节进度，因此不显示虚假的下载百分比或速度；日志中的近似大小标明“约”，未知总量标明“大小待确认”。磁盘占用包含既有缓存和解压文件，不等于本次网络流量。

显式 ASR 模型下载提供文件清单、真实下载字节/总量、平均速度及校验状态；来源未提供完整大小时不显示百分比。这不覆盖引擎库内部自动下载和旧 TTS 下载器。下载日志经过密钥脱敏。

关闭到托盘时服务继续运行；退出整个应用时，应用停止自己启动的服务。已有远程后端地址会保留，只有主动启动/连接本机服务时才切换。其他程序启动的后端不会被强制结束。

## 重复启动

同一 Windows 用户同时只运行一个 Amadeus 主实例。重复双击、从其他安装目录打开、使用开发/预览/测试配置启动，都会唤回当前窗口；最小化或缩到托盘的窗口会重新显示，不会再启动一套后端。

完全退出后才能切换程序版本或配置目录。异常结束后，操作系统释放原生单实例锁，下次可直接启动，无需手动删除锁文件。任务管理器中的渲染、GPU 等 Electron 子进程属于同一个应用，不代表多开。

旧版预览程序曾绕过单实例限制，需升级后才遵守此规则。运行 Windows E2E 测试前也应先完全退出当前 Amadeus。

## 基础安装覆盖什么

基础环境统一在 **首页** 安装和管理，所有任务共用，只需准备一次。基础安装覆盖本机后端、实时语音 API 适配、3D 数字人、配置与数据存储。实时语音不需要额外安装 Redis 或 Linux 服务。设置页保留应用偏好，不再重复提供环境安装和后端地址配置。

本地 ASR 权重可在 **语音识别 → 识别配置 → 模型下载** 按需下载，并点击 **安装本模型运行组件** 补齐该模型需要的依赖，无需重新初始化基础环境。详见 [模型智能下载](model-downloads.md)。CUDA 驱动和部分引擎要求的官方推理源码仍需单独准备；界面会区分权重与运行组件状态。基础安装不包含全部 GPU 依赖和模型权重。FFmpeg 也不是基础安装的一部分，依赖它的媒体转换功能需要另装。

## 按任务配置模型

- **首页**：首次准备环境；服务连接后优先显示继续任务和常用入口，展开底部“环境与连接管理”调整环境。侧栏默认保留文字，可手动折叠。
- **语音识别**：分别打开语音输入、文件转写、实时字幕、识别配置。页面右上角可直接选择、加载当前任务的模型。处理模板直接显示在语音输入和文件转写页面，点击即可切换；编辑模板只需展开一层。配置区分为 01 识别引擎、02 模型下载、03 热词纠错、04 文本整理，每次显示一类内容。离线与流式模型分别选择；文本整理区保留后处理模型连接设置。数字人导入在设置中管理。
- **实时对话**：主界面显示麦克风、语音输出与后台任务的独立状态，角色可收起。点“对话配置”打开引擎音色、角色记忆、工具任务侧栏；原生语音提供方密钥仍在其中管理。
- **总结**：分为生成、已保存和自动总结；模型与模板按需展开。生成中可停止并保留已输出内容；离开页面也会停止当前生成并保留草稿。
- **语音合成**：选择文字合成、语音转换或实时转换；模型配置与直播混音默认收起。生成完成后自行选择“本机试听”或“发送到所选输出设备”。活动任务可随时停止，离开页面会停止该页的采集与播放。

文本模型的服务连接保存接口、厂商和 API Key，各任务选择连接与模型。可以复用一份连接并选择不同模型，也可创建单独连接。更改共享连接会影响引用它的任务；更改本任务模型不影响其他任务。旧版本配置会自动迁移。

FormalASR 下载权重后，需要点击 **安装本模型运行组件**，安装成功后再 **加载**。本地模型默认使用 CUDA；FormalASR 和 Qwen3-ASR 默认选择 `cuda:0`，精度 `auto` 在 CUDA 上使用 bfloat16。需要 NVIDIA 显卡、驱动和 CUDA 版 PyTorch；只有 CPU 版 PyTorch 时会明确报错，不会自动改为 CPU。可以在模型详情的 **加载设备** 中手动选择 CPU 或自动；CPU 的自动精度为 float32。已有明确选择的设备会保留。安装组件会保留已下载权重，运行中的本机服务会停止后重启。

## 运行任务与异常恢复

录音、转写、字幕和页面注册的活动任务会显示在底部任务条，可查看或停止。快捷识别和批量转写可跨页运行；实时会话、语音合成和总结沿用各自的离页清理规则。停止等待在线合成结果会丢弃迟到响应，并不代表供应商已取消处理或计费。

数字人渲染失败会在角色区域内显示重试提示，不影响其他对话操作；页面级异常保留导航，并提供重试或返回首页。历史记录删除支持当页撤销，全部清空需确认。

## 给开发者：生成安装包

在已有 Node.js 构建环境的 Windows 上，从 `frontend/desktop` 运行 `npm run build:win`。

打包前自动执行 `scripts/windows/prepare_runtime.ps1`：下载固定版本 uv 0.10.4，核对固定 SHA-256，并携带上游许可证。后端只打包允许的 Python/JSON 源文件及 `pyproject.toml`、`uv.lock`，不包含 `.env`、数据库、日志或本地模型。

专用 Python 由 [uv 的 managed Python](https://docs.astral.sh/uv/concepts/python-versions/) 安装并限制在应用目录；基础依赖按项目锁文件安装。开发者的系统 Python、项目 `.venv` 和 PATH 不作为使用者的前置条件。
