# Windows 一键安装与启动

## 给使用者

1. 运行 `Amadeus-Windows-Setup-0.1.0.exe`，按向导安装到自己的用户目录。
2. 打开 Amadeus，点首页的 **安装本机环境**，或进入 **设置 → 常规 → 在这台电脑上运行**。
3. 点 **一键安装并启动**。程序会联网下载 Python 与锁定版本的基础依赖，安装进自己的目录；进度与失败原因会显示在界面。
4. 出现 **运行中 / 当前已连接** 后，点 **进入实时语音对话**，选择模型并填写自己的 API Key。
5. 如需 3D 数字人，在 **设置 → 本地 3D 模型** 导入自己有权使用的 GLB。公开版不附带角色模型；没有模型也可使用语音功能。导入有口型形态键的模型后，可用 **试听口型** 本地检查，不需要 API Key。

无需 Linux、WSL、Docker、管理员权限，也不用自己安装 Python、Node.js 或输入终端命令。前端已经包含在安装包内。

也可以提前点 **只安装环境**，使用时再点 **启动本机服务**。开启 **打开 Amadeus 时自动启动** 后，下次打开应用会自动启动已安装的服务；这个选项不会偷偷下载尚未安装的环境。

首次安装需要网络。下载时间取决于网速；失败后可以查看日志并重试。后续启动已安装环境不需要重新下载依赖。云端模型对话仍需联网，并遵循模型提供方的额度与收费规则。

## 环境与数据在哪里

界面的 **安装位置与日志** 会显示当前实际目录，并提供打开按钮。默认在当前用户的 Amadeus 应用数据目录 `local-runtime` 中：

- `app`：随安装包提供的后端代码和本地 Python 虚拟环境。
- `app/backend/.env`：在实时语音页面保存的本机密钥；安装包不带任何开发者密钥。
- `python`：程序专用 Python。
- 模型路径以 **模型管理 → 下载本地模型 → 保存到** 为准：Whisper 默认在 `models`，其他引擎沿用 `app/backend/models` 或 `app/thirdparty` 下的适配器目录；修复环境会保留这些权重。
- 日志路径以界面显示为准。

关闭到托盘时服务继续运行；退出整个应用时，应用停止自己启动的服务。已有远程后端地址会保留，只有主动启动/连接本机服务时才切换。其他程序启动的后端不会被强制结束。

## 基础安装覆盖什么

基础安装覆盖本机后端、实时语音 API 适配、3D 数字人、配置与数据存储。实时语音不需要额外安装 Redis 或 Linux 服务。

本地 ASR 权重可在 **模型管理 → 下载本地模型** 按需下载，并安装相应 Python 运行组件，详见 [模型智能下载](model-downloads.md)。CUDA 驱动和部分引擎要求的官方推理源码仍需单独准备；界面会区分权重与运行组件状态。基础安装不包含全部 GPU 依赖和模型权重。FFmpeg 也不是基础安装的一部分，依赖它的媒体转换功能需要另装。

## 给开发者：生成安装包

在已有 Node.js 构建环境的 Windows 上，从 `frontend/desktop` 运行 `npm run build:win`。

打包前自动执行 `scripts/windows/prepare_runtime.ps1`：下载固定版本 uv 0.10.4，核对固定 SHA-256，并携带上游许可证。后端只打包允许的 Python/JSON 源文件及 `pyproject.toml`、`uv.lock`，不包含 `.env`、数据库、日志或本地模型。

专用 Python 由 [uv 的 managed Python](https://docs.astral.sh/uv/concepts/python-versions/) 安装并限制在应用目录；基础依赖按项目锁文件安装。开发者的系统 Python、项目 `.venv` 和 PATH 不作为使用者的前置条件。
