# 会议旁听与独立解释验收

> 当前行为以文末「2026-09-10：流式解释与一小时回看」为准；前面的触发后收集记录为历史验收。

原有实时对话页面新增「会议旁听与解释」模式，保留 X-ASR / Codex 架构。详见
[会议接口与使用方式](../asrapp/backend/CODEX.md#会议旁听与独立解释)。

- 持续 ASR：手动结束，不启用 VAD，不配置流式 Agent，解释期间持续采集。
- 触发：原文截取/选择、页面快捷键 Ctrl+Alt+E、可配置语音口令。
- 解释输入：提交时固定快照，默认附带最多 8000 字符的较早前文；语音触发优先关注后续话语。
- 语音收集：触发后默认继续收集 12 秒，可调整为 3–60 秒，或立即提交/取消；最多附带 4000 字符后文。
- 隔离：后端为每个解释创建独立会话，完成后释放；不接收原对话会话 ID 或角色记忆。
- 输出：文字卡片并展示对应原话，关闭 TTS 和旁听录音归档。

## 语音口令规范化修复

此前口令仅忽略大小写，ASR 插入逗号或空格就会漏触发。现在口令与转写统一进行 NFKC、
大小写及 Unicode 标点/空白/格式字符规范化；保留原始 UTF-16 位置映射，解释对象仍取原文，
不含口令。拒绝空白或纯标点口令，不执行用户输入的正则，并检查英文单词边界。

## 2026-09-09：增加上下文并优先关注触发后话语

Codex Agent 的任务提示现在区分触发前原话、较早前文和触发后话语。语音触发时要求 Agent
优先关注后面的几句话，结合背景自行判断当前话题、相关概念及解释范围；后续内容不足时
才回看触发前原话。按钮选择原文仍优先解释所选内容，每次请求保持独立会话。

前文上限由 2000 增至 8000 字符并默认附带，可关闭；触发后另收集最多 4000 字符。
默认收集 12 秒，可设为 3–60 秒，也可立即提交或取消。停止或断线取消未提交的收集；
提交后固定快照，持续 ASR 不暂停，也没有增加 VAD。

前端 33 项、后端 16 项测试通过；TypeScript、相关 Ruff 和 git diff --check 通过。
覆盖触发后增量转写、口令在整段开头、定时提交、提前提交、停止时取消、默认/关闭前文、
8000 字符背景及请求上限、独立会话和 Agent 提示内容。

最终真实端到端产物：`.runtime/meeting-ui/1788883300610/report.json`，`passed=true`。
实际 PCM → X-ASR → Codex，触发前讨论数据库和乐观锁，触发后明确询问委员会会议为什么
需要超过半数成员出席。Agent 明确指出话题已切换，解释会议法定人数及代表性；再次手动
询问缓存 TTL 时使用另一会话，正确解释缓存过期，没有沿用会议法定人数或乐观锁。
持续上传音频、无额外解释、无流式 Agent 事件、无 TTS、停止后停止上传等断言通过。

验收中发现的限制：初次合成音频里的 quorum 被识别为 acquire，Agent 因而结合数据库前文
作出了分布式仲裁解释并提示不确定性。换用明确的委员会会议表述后通过。另一次 ASR 合并了
触发前两句话，背景因此在 target 而不是 preceding_context；测试已改为检查触发前内容是否
保留，不强制 ASR 输出句号。更长上下文及重点提示不能消除识别错误和语义歧义。


## 2026-09-10：触发前回看与可配置解释方向

按新的交互要求移除触发后收集。语音口令、时间窗按钮和可配置快捷键均立即提交此前的一段会议，
默认回看 120 秒（10–900 秒），默认重点关注末尾 30 秒。手动选中或编辑原文仍优先解释所选内容。
口令和同次 ASR 事件中的后续话语不会进入当前请求；修订重复口令不重复提交。

新增本机持久化设置：回看时长、末尾时长、末尾关注程度 1–5、预置提示词、关注要点、
是否附带更早前文、口令开关及内容、快捷键开关及组合键录制。Agent 提示明确区分用户方向和会议资料，
每次请求独立会话；末尾关注程度是任务优先级提示，不声称能控制模型内部 attention。

快捷键默认 Ctrl+Alt+E，可录制 Ctrl/Alt/Meta 与字母、数字或功能键的组合；忽略自动重复与输入法组合事件，
编辑文本时不触发。它是页面快捷键，不是操作系统全局热键；浏览器保留组合键可能无效。

时间窗以转写首次到达时间近似计算，保留修订文字的时间信息，不是音频逐字时间戳。
保留最多 64000 字符转写，单次原文最多 12000、末尾重点最多 2000、更早前文最多 8000 字符。
原文被显式编辑时清除自动末尾重点，避免把旧重点带入新解释。

## 2026-09-10：流式解释与一小时回看

会议 UI 改用 `/v1/agents/codex/explanations/stream`，转发 Codex 的真实增量事件。
前端按网络流解码、追加显示中文，收到完成事件后更新最终回答与用量；提供停止生成，
断流或取消时保留已收到文字并提示未完成。HTTP 断开会取消后台请求并释放独立会话，旁听不停止。

默认回看 3600 秒（最大一小时），默认重点关注最后 60 秒。旧默认 120/30 秒自动迁移，
保留自定义快捷键、预置提示词等。原文上限扩到 96000 字符、末尾重点 8000、转写保留 128000，
超出限制时有可见提示；生成超时延长至 300 秒。时间窗仍按 ASR 首次出现时间近似计算。

- 前端 40 项通过：中文 UTF-8 跨分块、CRLF SSE、完成前显示增量、断流提示、停止生成、
  持续旁听、旧设置迁移、65 分钟模拟时间线中一小时的 50000+ 字符及最后一分钟截取。
- 后端 19 项通过：增量先于完成事件、完整用量、实际运行中的模拟 Agent 取消和会话清理、
  一小时请求与大文本参数校验。
- TypeScript、相关 Ruff 与 git diff --check 通过。
- 真实 PCM → X-ASR → Codex → SSE → UI 测试通过：
  `.runtime/meeting-ui/1789055039971/report.json`，`streamVisible=true`，两次回答共 275 个 delta。
  两次请求均携带 3600/60 秒设置，会议窗口持续上传 491 个 PCM 帧，TTS 为 0。
